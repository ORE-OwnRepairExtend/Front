# 🔧 ORE — Own Repair Extend

> 제품의 정보를 기록하고 관리하여 더 오래 사용할 수 있도록 돕는 제품 생애주기 관리 서비스

ORE는 제품 등록, 보증 관리, 수리 이력 기록, 공식 정보 확인 등을 통해 사용자가 제품을 더 오래 사용할 수 있도록 돕는 웹 서비스입니다.

제품 구매 이후 흩어져 관리되는 제품 정보와 수리 기록을 하나로 연결하고, 제품 관리 챗봇과 알림 기능을 통해 제품을 지속적으로 관리할 수 있도록 지원합니다.

## 💡 Background

제품을 구매한 이후 보증서, 사용 설명서, 수리 내역과 제품 정보는 서로 다른 장소에서 관리됩니다.

이로 인해 사용자는 필요한 정보를 찾기 어렵고, 수리 가능 여부를 충분히 확인하지 않은 채 제품을 교체하거나 폐기하기도 합니다.

ORE는 제품과 관련된 정보를 하나의 서비스에서 관리하고 적절한 시점에 보증·수리·알림 정보를 제공하여 제품의 사용 기간을 연장하기 위해 기획했습니다.

## 🔍 Technical Highlights

### 인증 요청과 토큰 재발급 구조

인증이 필요한 요청을 공통 Axios 인스턴스에서 처리하고, accessToken이 만료된 경우 재발급할 수 있도록 인증 통신 구조를 구성했습니다. 로그아웃 시 사용자 인증 상태가 남지 않도록 관련 처리도 함께 개선했습니다.

### 여러 챗봇 세션의 상태 동기화

사용자가 새로운 채팅을 시작하거나 이전 채팅으로 이동할 때 채팅 목록, 선택된 세션과 대화 내용이 일치하도록 세션 생성·목록 조회·메시지 조회 로직을 연결했습니다.

새로운 세션 생성 후 이전 채팅 목록을 갱신하고, 선택된 세션에 따라 메시지와 입력 가능 상태가 변경되도록 구현했습니다.

### OCR 기반 제품 등록 흐름

OCR을 통해 추출한 제품 정보를 곧바로 저장하지 않고 사용자가 결과를 확인하고 수정할 수 있는 흐름으로 구성했습니다.

제품 이미지 등록, OCR 결과 확인, 입력 데이터 정리, 제품 등록 API 호출을 단계적으로 연결했습니다.

### 제품 상태별 예외 처리

구매일, 보증기간, 제품 이미지, 사용자 프로필 이미지처럼 값이 없을 수 있는 데이터를 화면에서 안전하게 처리했습니다.

보증 정보가 없는 제품에 불필요한 API 요청이 발생하지 않도록 방지하고, 이미지가 없거나 로드되지 않는 경우 기본 이미지를 제공했습니다.

### 수리 예정과 수리 이력의 연결

수리 예정 정보를 단순 알림으로 끝내지 않고, 완료 처리 후 수리 이력 등록 과정으로 이어지도록 화면 상태와 초기 입력값을 연결했습니다.
